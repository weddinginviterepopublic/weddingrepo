Put files here and they show up on the site by themselves.

- photos/  .jpg .jpeg .png .webp   (shown in the gallery, in file-name order)
- music/   .mp3 .m4a .ogg          (the first file is the background music)
- videos/  .mp4 .webm              (short clips only; each file must be under 100 MB)

For longer videos, upload to YouTube and add the link in config.js.
Resize photos to about 2000 px wide before uploading so the page loads fast.
