# Mahisa & Karteek wedding website

A single-page wedding site, hosted free on GitHub Pages.

## Turn on hosting
1. Repo Settings -> Pages.
2. Source: "Deploy from a branch". Branch: `main`, folder: `/ (root)`. Save.
3. After a minute the site is live at https://weddinginviterepopublic.github.io/weddingrepo/

## Editing
Everything is in `index.html`. To switch on the RSVP button, paste your
link into `RSVP_URL` near the bottom of the file.
